2026 SEO Naming Guidelines

1. Image File Naming

Google uses filenames as a primary signal to understand the subject matter. Rename files before uploading.

❌ Bad Examples:
• IMG_0452.jpg (No context)
• best-coffee-cheap-coffee-beans.jpg (Stuffing)
✅ Good Examples:
• organic-medium-roast-coffee.webp (Descriptive)
• san-francisco-skyline.avif (Concise)

2. Folder Structure

Folder structures provide a hierarchical map for crawlers. Grouping similar content establishes topical authority.

❌ Bad Structure:
/images/1/file.jpg
✅ Good Structure:
/products/office-chairs/high-back.jpg
/blog/2026/fix-leaky-faucet.html

Summary Checklist

  • Separator: Use Hyphens (-) not underscores or spaces.
  • Case: Always lowercase.
  • Length: 3-5 descriptive words.
  • Format: Use WebP or AVIF for images.
